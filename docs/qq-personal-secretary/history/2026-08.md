- `mysql_memory_candidate.rs` 新增三个路径：
  1. 远程 `claim`：`INSERT IGNORE` 批次范围内被过滤 local_only（限定全局二元组边界，保证在
     游标之前或等位）→ 远程主领取不重复读到这些事件（`> 游标`）
  2. 本地 `claim`：优先 `claim_deferred_batch` → 清理不可处理死行 → 最早会话连续前缀 →
     `next_cursor = 当前主游标`（不推进，延期事件已在游标之前或等位）
  3. `commit`：同一事务 `DELETE` 本批次延期行（延期批次主清理；本地主批次覆盖游标 NULL 边界
     同事件行；远程主批次空操作）
- 崩溃窗口走查：claim 已提交但 commit 未执行 → 游标未动、INSERT IGNORE 幂等；游标 NULL 时
  跳过延期路径，主领取全量覆盖并清理延期行。
- 新增 Codex 指定回归测试 `memory_candidate_local_only_before_normal_survives_remote_then_local`：
  L1(local_only) + N1(normal) → 远程领 N1 游标越过 L1 → 切本地仍领取 L1 → 排空后无重复。
