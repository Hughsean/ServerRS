# 正常人 QQ 聊天行为模型 —— 赛博猫猫能力蓝图

> 创建日期：2026-06-16
> 状态：初稿，待细化拆分为实施单元

## 背景

赛博猫猫是一个活跃在 QQ 群聊中的 AI 猫娘机器人。目标是让它像一个真实的人一样聊天，而不仅仅是一个问答机器。本文档梳理了一个正常人在 QQ 聊天中会展示的所有行为维度，作为后续迭代的能力蓝图。

---

## 八大行为维度

### ① 响应触发方式（什么时候说话）

- [ ] **被 @ 时回应** — 最基本的触发，已实现
- [ ] **被引用回复时回应** — 有人引用猫猫上一条消息，有义务回应
- [ ] **关键词触发** — 听到感兴趣的话题主动插话（已有关键词匹配逻辑雏形）
- [ ] **被拍一拍时反应** — 被 poke 后回一个 poke 或说话
- [ ] **冷场救急** — 群聊超过 N 分钟无人说话时，主动发话题
- [ ] **冒泡** — 很久没说话了（跨小时/天），主动打招呼
- [ ] **自发分享** — 遇到想说的、想分享的，主动发起对话
- [ ] **周期性问候** — 早安/晚安/午间问候
- [ ] **节日/特殊日子触发** — 春节、中秋、群友生日等
- [ ] **群状态变化触发** — 新人进群时欢迎，有人退群时（可选）

### ② 回复的内容形式（怎么说话）

- [x] **纯文字** — 已完成
- [x] **QQ 表情（face）** — 已完成
- [x] **颜文字** — 已完成
- [ ] **图片/表情包** — 已有 Image 段类型，但缺少表情包选择逻辑（从哪儿拿图？随机表情包库？）
- [x] **引用回复** — 已完成
- [x] **拍一拍（poke）** — 已完成
- [x] **语音消息（record）** — 已完成
- [ ] **合并转发消息** — 复杂场景，暂缓
- [ ] **链接分享** — 可考虑

### ③ 情绪与态度表达（什么语气说）

- [ ] **基础情绪** — 开心 🎉、难过 😿、惊讶 😳、生气 😾、无奈 🤷
- [ ] **社交语气** — 调侃、吐槽、安慰、鼓励、认真、敷衍、"懒得理"
- [ ] **撒娇/卖萌** — 猫娘特色，适当使用
- [ ] **得意/炫耀** — "嘿嘿我厉害吧"
- [ ] **谦虚/自嘲** — "啊这个我不太懂"
- [ ] **情绪递进** — 从平淡→兴奋有个过程，而不是突变
- [ ] **情绪记忆** — 刚才还在生气呢，不会下一秒就开心得像没事一样

### ④ 社交关系处理（对不同人怎么说）

- [ ] **熟人 vs 陌生人区分** — 对经常聊天的群友更随意亲近，对新来的更礼貌
- [ ] **对群主/管理 vs 普通群友** — 对管理稍加尊重（不一定需要）
- [ ] **对不同性格调整互动** — 知道谁喜欢被调侃、谁开不起玩笑
- [ ] **记住群友的称呼偏好** — 有人喜欢被叫昵称、有人介意
- [ ] **@使用** — 合适的时候 @对方，而不是每次都说"那个谁"
- [ ] **关系记忆** — 记得谁和谁关系好、谁是死对头

### ⑤ 话题管理（聊什么）

- [ ] **话题跟踪** — 当前在聊什么话题，不要答非所问
- [ ] **话题切换** — 自然过渡（"对了说到这个……"），而非生硬转折
- [ ] **发起话题** — 主动开新话题
- [ ] **延续话题** — 别人接话了就继续聊
- [ ] **结束话题** — 自然收尾（"行那先这样~"）
- [ ] **避开敏感话题** — 政治、引战内容主动回避或打哈哈
- [ ] **话题热度判断** — 如果某个话题没人响应，不要再追着说
- [ ] **多线程对话** — 群聊中可能同时有两三个话题在并行，能区分

### ⑥ 时间与场景感知（什么时候聊）

- [ ] **时段感知** — 早上精神、中午休息、晚上放松、深夜安静
- [ ] **工作日 vs 周末** — 工作日白天少聊、周末可以多聊
- [ ] **节日感知** — 春节拜年、中秋团圆、愚人节整活
- [ ] **长时间离线后回归** — 几小时/几天没说话后再出现时自然解释或打招呼
- [ ] **群活跃时段** — 了解这个群什么时候人多，在合适的时间冒泡
- [ ] **回复时效** — 被晚回复时要说明（"刚才在忙~"）

### ⑦ 对话上下文能力（聊得连贯）

- [x] **最近消息回顾** — 已有最近 20 条消息作为上下文
- [x] **发言人标注** — 已区分谁说了什么
- [ ] **省略/指代理解** — "那个""就他""昨天你说的" — 理解省略表达
- [ ] **对话内自我记忆** — 记得自己在这个对话里说过什么，避免重复
- [ ] **多轮进展感知** — 理解一个问题从提出→讨论→解决的进展
- [ ] **谁在跟谁说话** — 区分 @某人、引用某人、对全体说话
- [ ] **避免重复** — 不要两轮连续说一样的内容
- [ ] **上下文窗口扩展** — 当前只有 20 条，有些上下文需要更多历史
- [ ] **关键信息摘记** — 对话中提到的重要信息（时间、约定等）自动记住

### ⑧ 主动行为（不等人说就做）

- [ ] **主动关心** — "XX 今天怎么没说话""XX 还好吗"
- [ ] **分享趣味** — 看到有意思的东西发群里
- [ ] **约局** — "有人打游戏吗""今晚吃啥"
- [ ] **提醒** — 如果有约定时间，到时提醒
- [ ] **捧场** — 别人发了图片/分享，即使不知道说什么也回应一下
- [ ] **告状/打小报告** — 群友特色行为，可选
- [ ] **自夸** — "我可是赛博猫猫诶~" 人设需要

## 下一步计划

这份文档作为顶层蓝图，后续会拆分为多个独立的实施项目，每个项目遵循 brainstorm → design → plan → implement 的流程。

首批优先级的候选项目（待讨论确定顺序）：

1. **情绪系统** — 让猫猫有稳定可感知的情绪状态，回复语气随情绪变化
2. **时间感知** — 让猫猫知道现在是早上还是晚上，工作日还是周末
3. **主动发言** — 冷场救急、长时间沉默后冒泡
4. **社交关系** — 区分熟人和陌生人，调整语气
5. **对话上下文增强** — 省略理解、避免重复、对话内记忆
6. **话题管理** — 话题跟踪、切换、发起
7. **表情包系统** — 从本地/网络选择合适表情包发送
